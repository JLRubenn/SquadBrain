# projeto-quidgest

Para rodar o projeto:

1.Abrir pasta: GEN_QUIDGEST>MYAPP
2.Abrir o Docker 
3.Para Windows: Executar o ficheiro start.bat
  Para MAC ou Linux, abrir o ficheiro start.bat e seguir as instruções que estão lá.
4.Esperar que faça docker compose 
5.A instalação do ambiente inicia, e para continuar deve ir pressionando em teclas
consoante a solicitação. 
6.Abrir o localhost:3030 (genioapp-1)
